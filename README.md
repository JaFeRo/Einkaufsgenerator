# Einkaufsgenerator – dAKZ Bonsimulator

Erzeugt Test-Kassenbons mit QR-Codes nach der „Schnittstellendefinition QR-Code“ der Generalzolldirektion (digitaler Ausfuhrkassenzettel, dAKZ), um das Einscannen zu testen.

- Design & Plan: [`docs/PLAN.md`](docs/PLAN.md)
- Prototyp: [`prototype/index.html`](prototype/index.html) im Browser öffnen (lädt `qrcode-generator` von cdnjs)

Alle erzeugten Belege sind Testdaten mit fiktiven Händlerangaben und keine steuerlich gültigen Belege.
